<h1 align="center">📚 cpp-dsa-notes</h1>

Beginner-friendly **Data Structures and Algorithms (DSA) notes in C++**, written for students who want to understand the concepts first and then practise them until they can explain and implement them without looking at the notes.

Each chapter explains the idea in plain language, shows modern C++ code, and uses **animated diagrams** so you can watch operations like insertion, deletion, and reallocation step by step instead of reading static pictures.

## 🎯 What you will find in each chapter

- A clear explanation of the concept and why it matters
- C++ code examples you can compile and run
- Animated diagrams for the key operations
- Time and space complexity with the reasoning behind it
- An interview-ready recap and a practice checklist

## 🛠️ How to run the code

The examples use standard C++ and compile with any modern compiler. For example, with GCC or Clang:

```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o main
./main
```

Verify code against the compiler and C++ standard version you use.

## 🧭 How to study with these notes

1. Read the chapter once and watch the animations.
2. Type the examples yourself instead of copy-pasting.
3. Work through the practice checklist at the end of the chapter.
4. Explain each concept out loud, as if teaching someone else.
